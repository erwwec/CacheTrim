# CacheTrim — бриф на редизайн

Документ для дизайнера/ИИ, который будет переделывать интерфейс. Здесь всё, что нужно,
чтобы не сломать работающее приложение: цель, жёсткие ограничения, карта файлов, все
дизайн-токены, инвентарь контролов с точной геометрией, разбор каждой страницы, список
известных косяков и рецепт сборки/проверки.

---

## 1. Что это за приложение

**CacheTrim** — утилита для Windows 11/10 в духе RAMMap + «оптимизатора» Windows.

Что реально делает:

- освобождает память нативными вызовами (`NtSetSystemInformation` 0x50 с командами 2/3/4/5
  — рабочие наборы, standby, low-priority standby, modified page list; `SetSystemFileCacheSize(-1,-1,0)`
  для системного кэша ФС) — не «placebo»-очистка, а те же вызовы, что у RAMMap;
- чистит temp, кэши браузеров, кэш шейдеров, эскизы, WER, дампы, кэш Windows Update,
  UWP-кэши, prefetch, старые логи, корзину, DNS/ARP/NetBIOS;
- страница твиков Windows (службы, телеметрия, план питания, интерфейс, ФС) с полным откатом;
- отключает записи автозагрузки с резервом (ничего не удаляет);
- ставит задачу планировщика «при входе в систему» с задержкой.

Язык интерфейса — **русский**. Тон текстов — сухой технический, без маркетинга.

## 2. Жёсткие ограничения (нельзя нарушать)

| Ограничение | Причина |
|---|---|
| **Только .NET Framework 4.x и `csc.exe` из Windows** | На машине нет .NET SDK, нет NuGet, нет `dotnet`. Сборка идёт `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`. |
| **Язык C# 5** | Никаких интерполяций `$"..."`, `?.`, expression-bodied членов, `nameof`, кортежей, `async/await` в стиле C# 6+. |
| **WinForms, никаких сторонних пакетов** | Никаких WPF, WebView2, Avalonia, SkiaSharp, ImageSharp. Только `System.Windows.Forms`, `System.Drawing`, `System.Drawing.Drawing2D`. |
| **Тёмная тема обязательна** | Системные контролы (CheckBox, NumericUpDown, ScrollBar, Button, ProgressBar) на тёмном фоне выглядят как белые заплатки — поэтому все они **саморисуемые** (см. `src/Controls.cs`). |
| **`requireAdministrator` в манифесте** | Без прав не работают привилегии `SeProfileSingleProcessPrivilege` / `SeIncreaseQuotaPrivilege`. |
| **Файлы `.cs` в UTF-8 без BOM, LF** | `build.ps1` передаёт `csc` `/codepage:65001`. PowerShell 5.1 читает UTF-8 без BOM как ANSI — не редактировать `Get-Content`/`Set-Content`. |
| **`build.ps1` глобит `src\*.cs`** | Новый файл подхватывается автоматически, править скрипт не нужно. |
| **Приложение не должно падать без прав** | Все ветки «нужен админ» обрабатываются сообщением в журнал, а не исключением. |

Окно: `ClientSize = 1120×760`, `MinimumSize = 1010×700`, `StartPosition = CenterScreen`,
`DoubleBuffered = true`, иконка `SystemIcons.Shield`.

`Content.ClientSize.Height - footer.Height` на каждом `Content.Resize`. Не убирать —
иначе контент уезжает под кнопки.

## 6. Инвентарь контролов (`src/Controls.cs`)

Все — саморисуемые (`UserPaint | OptimizedDoubleBuffer | ResizeRedraw`). Ни один не
использует системный рендер.

### `UiButton : Button`

- `Height = 38`, шрифт `Segoe UI Semibold 9`, `FlatStyle.Flat` с `BorderSize = 0`,
  `Cursor.Hand`, `TabStop = false`.
- `Accent = true` (primary): заливка `Accent`, hover — `Blend(Accent, White, 0.10)`,
  нажатие — `Blend(Accent, Black, 0.12)`, текст `#0D0E1B`.
- `Accent = false` (ghost): заливка `SurfaceAlt`, hover `Hover`, граница `Line`
  (на hover — `Blend(Line, White, 0.10)`), текст `Text`.
- Радиус 7, текст по центру с `EndEllipsis`.
- Фабрики: `Ui.Primary(text)` и `Ui.Ghost(text)` в `src/Pages.cs`.

### `ToggleSwitch : CheckBox`

- Размер 42×22, без подписи (`Text` пустой — название живёт рядом в строке).
- Трек: `Rectangle(0, 2, Width-1, Height-5)`, радиус = половина высоты.
- Выключен: `#2C333D`, hover `#38404C`. Включён: `Accent`, hover `Blend(Accent, White, 0.10)`.
- Бегунок: круг `track.Height-6` = 12 px, отступ 3 px от края.
  Выключен — `#9AA6B4`, включён — `#09140E`.

### `DarkCheck : CheckBox`

- Высота 22, `BackColor = Surface`, шрифт `Segoe UI 9.5`, текст с отступом 24 px.
- Квадрат 16×16 по вертикальному центру, радиус 4.
- Выключен: заливка `#14181E`, граница `Line` (hover `#4E5866`).
- Включён: заливка `Accent`, галочка пером `#09140E` 1.8 px (ломаная 4→7→12).
- `OnPaint` начинается с `g.Clear(BackColor)` — прозрачность не поддерживается,
  поэтому `BackColor` обязан совпадать с фоном родителя.

### `Chip : Control`

- Размер по умолчанию 96×20, шрифт `Consolas 7.25 Bold`.
- Пилюля: заливка `FromArgb(26, Tone)`, обводка `FromArgb(64, Tone)`, текст `Tone`.
- `Set(caption, tone)` — поменять подпись и цвет.
- Используется для источника записи автозагрузки (`HKCU\Run`, `HKLM\Run`, `Папка автозагрузки`).

### `Stepper : Control`

- Размер 150×32 (в настройках используется 132×32), фон `Bg`, шрифт `Consolas 10 Bold`.
- Поле: `Rounded(...,7)`, заливка `SurfaceAlt`, обводка `Line`.
- Зоны `−` и `+` по 30 px, при hover заливаются `Hover` радиусом 6.
- Знаки рисуются пером `Muted` 1.6 с круглыми концами, длина луча 5 px.
- Число по центру между зонами (`32 … Width-64`), `Consolas 10 Bold` `Text`.
- Клик по зоне меняет значение на 1, колесо мыши — тоже. Есть `ValueChanged`.

### `RowPanel : Panel`

- Строка внутри карточки, фон `Surface`, `DoubleBuffered`.
- Рисует нижнюю волосяную линию `RowLine` по `Height-1`, если `ShowDivider = true`.
- Так таблица выглядит без таблицы: строки разделены волоском, а не рамками.

### `ScrollHost : Panel`

- Тёмный саморисуемый вертикальный скролл. `Gap = 14` между элементами,
  `Gutter = 22` (ширина, отданная под скролл), `BottomPad` — дополнительный низ.
- Элементы кладутся сверху вниз: `Add(control)`, ширина = `ClientSize.Width - Gutter`.
- Полоса: трек `Rectangle(Width-9, 4, 5, ClientSize.Height-8)` цветом `#1A1E24`,
  бегунок 5 px шириной, радиус 2, цвет `#3E4652`, при перетаскивании — `Accent`.
- Минимальная высота бегунка 30. Колесо мыши — `ScrollBy(delta)` (60 px на щелчок).
- `ScrollBy`, а не `Scroll` — базовый `ScrollableControl.Scroll` перекрывался.

### `CardPanel : Panel` (`src/Theme.cs`)

- Заливает `Bg` и рисует карточку `Theme.Card(...)`: скруглённый прямоугольник `Surface`
  радиусом 10 с обводкой `Line`.
- **Важно:** дети карточки обязаны иметь `BackColor = Theme.Surface`, иначе на скруглённых
  углах и вокруг текста появляются светлые прямоугольники. `Label` с `BackColor = Transparent`
  над такой карточкой **не отрисовывается** — использовать явный `Surface`.

### `StatCard : Control`

- Карточка-счётчик для страницы «Память». Поля `Caption`, `Value`, `Detail`, `Accent`, `Fraction`.
- Подпись `Segoe UI Semibold 8` `Faint` в `(14, 12)`.
- Значение `Value` (Consolas 15 Bold) `Text` в `(12, 30)`.
- Деталь `Small` `Muted` в `(14, Height-36)`.
- Полоса `Theme.Bar` в `Rectangle(14, Height-16, Width-28, 4)`, трек `#22272F`.

### `Sparkline : Control`

- Ёмкость 120 точек (по тику 1.5 с ≈ 3 минуты). `Add(double 0..1)`.
- Карточка + подпись «ЗАГРУЗКА ПАМЯТИ · ПОСЛЕДНИЕ 3 МИНУТЫ» в `(14, 12)`.
- Плот: `Rectangle(14, 40, Width-28, Height-58)`.
- Сетка: 5 горизонтальных линий `#1E232A`.
- Метки «100%» и «0%» `Small` `Faint` у правого края.
- Заливка под кривой — градиент `FromArgb(70, Accent)` → `FromArgb(0, Accent)` сверху вниз.
- Линия `Accent` 1.8 px, `LineJoin.Round`.
- Текущее значение `Consolas 11 Bold` `Accent` в правом верхнем углу.
- Пока нет истории — рисует плоскую линию во всю ширину плота.

### `Ui.Text(...)` (`src/Pages.cs`)

Фабрика `Label` с `AutoSize = false` и **`BackColor = Transparent`**. Годится только там,
где родитель — обычный `Panel` с однотонным фоном (`Bg`/`Surface`), но **не** над
`CardPanel`. Для карточек создавать `Label` вручную с `BackColor = Theme.Surface`.

## 8. Что именно не нравится владельцу (список дизайн-долга)

Приложение работает; претензия — «дизайн должен быть адекватный». Конкретно:

1. **Плотность.** Строки по 54 px при 19 пунктах дают длинный скролл. Можно ужать до 46–48
   или сделать двухколоночную раскладку на широких окнах.
2. **Настройки не используют ширину.** Карточки фиксированы 640 px, справа пусто.
3. **Журнал** — единственное место с системным светлым скроллбаром и «чужой» типографикой.
4. **Страница «Память»** — карточки-счётчики хороши, но график занимает всю середину
   и на большом окне выглядит пустым; нет горизонтальной шкалы времени и подписей оси Y.
5. **Нет нигде иконок-статусов** в строках (только текст), нет группировки-аккордеона.
6. **Нет адаптива:** `MinimumSize` 1010×700, но раскладка рассчитана на 1120×760;
   на 1010 карточки памяти сжимаются до минимума 120 px и текст обрезается.
7. **Кнопки-футеры** всегда слева и одинаковой высоты; на страницах с одной кнопкой
   правая часть футера пустая.
8. **Рельс** статичен: 6 пунктов, нет секций, нет бейджей («нужен перезаход», «отключено 3»).
9. **Нет тёмной темы окна** — заголовок окна и рамка остаются системными светлыми
   (`DwmSetWindowAttribute` не используется). Это самый заметный «недо-Dark».
10. **Скроллбар в журнале** светлый — единственный не-саморисуемый контрол.

## 9. Сборка и проверка

```powershell
cd CacheTrim
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Успех — строка `OK  …\dist\CacheTrim.exe  <N> bytes` и **ноль предупреждений**
(сборка идёт с `/warn:4`). Сейчас 102 912 байт.

Запуск:

```powershell
Start-Process .\dist\CacheTrim.exe -ArgumentList "--page=2"
```

`--page=N`: 0 Память, 1 Очистка, 2 Оптимизация, 3 Автозагрузка, 4 Журнал, 5 Настройки.
Есть `--silent` — headless-проход для задачи планировщика, пишет `history.log`, код 0/1.

Скриншот окна (окно должно быть запущено):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\grab.ps1 -Process CacheTrim -Out .\docs\shot.png
```

`grab.ps1` снимает через `PrintWindow(..., 2)`, поэтому перекрытие другими окнами не мешает.
**Держать инструменты вне `%TEMP%`** — приложение реально чистит `%TEMP%`.

### Ловушки, на которых уже обжигались

- `Label` с `BackColor = Transparent` над `CardPanel` не рисуется — только явный `Surface`.
- Анкоры считаются от текущей ширины родителя: `Panel` по умолчанию 200 px, поэтому
  карточку/строку надо создавать сразу нужной ширины (800), иначе `Top|Right` уводит
  контрол за экран (было: чипы на `x = 1286`).
- `Dock.Bottom` + `Dock.Fill` зависят от z-порядка — использовать `FitAboveFooter`.
- `Controls.SetChildIndex(control, index)`, а не `Panel.SetChildIndex`.
- C# 5: без интерполяции строк, без `?.`, без expression-bodied членов.
- Файлы, записанные инструментом `write`, имеют **LF**; правки через PowerShell по `\r\n`
  молча не срабатывают — использовать `\n` или инструмент `edit`.
- PowerShell 5.1 читает UTF-8 без BOM как ANSI: для кириллицы только
  `[System.IO.File]::ReadAllText/WriteAllText` с `New-Object System.Text.UTF8Encoding($false)`.

## 11. Актуальное состояние после редизайна

Этот раздел уточняет первоначальные геометрические значения выше: при расхождении
использовать значения из этого раздела и фактическую реализацию в `src\`.

- Палитра обновлена в `Theme.cs`: `Bg #0A0D11`, `Surface #11161D`,
  `SurfaceAlt #181F28`, `Hover #1F2833`, `Line #27323F`, `RowLine #1C252F`,
  `Text #EDF2F8`, `Muted #919EAE`, `Faint #5E6C7D`, `Accent #8B8CFF`,
  `AccentSoft #27274C`. Семантические красный и янтарный сохранены;
  `Blue #53B1FF`, `Violet #BE8BFF`.
- Навигация имеет ширину 224 px; активный пункт использует световой акцент и отдельную
  секцию «Инструменты». Заголовки страниц имеют вертикальный акцент и градиентный разделитель.
- Карточки памяти перестраиваются из 4 колонок в 2 на узком окне. График заполняет
  не наблюдавшуюся часть окна первым измерением, чтобы оставаться читаемым сразу после запуска.
- Внизу страницы «Память» три действия: «Очистить память», «Полный прогон»,
  «Диагностика системы». Диагностика открывает отдельное тёмное окно только для чтения:
  Windows, разрядность, число логических процессоров, RAM, commit, standby, процессы,
  дескрипторы, системный диск и права.
- «Очистка» и «Оптимизация» показывают карточки в двух колонках на широком окне и в одной
  колонке на узком. Строки очистки и твики уплотнены до 48 px.
- Страница «Оптимизация» имеет модули `Windows` (18 пунктов) и `Игры` (3 пункта).
  Кнопки «Применить модуль» и «Вернуть по умолчанию» действуют только на выбранный модуль.
  Игровые пункты: игровой режим Windows, системный Game DVR и фоновая запись клипов.
- Карточки настроек занимают доступную ширину. Статус в футере оптимизации привязан к правому краю.
- В карточках действий модуля доступны штатная оптимизация дисков Windows (`defrag /o`),
  проверка защищённых системных файлов (`sfc /scannow`) и переходы в графические и игровые
  настройки Windows. Команды обслуживания требуют повышенных прав и явного подтверждения.
- В настройках доступна проверка GitHub Releases для `erwwec/CacheTrim`. Обновление EXE
  принимается только с HTTPS GitHub asset URL, проверяется по SHA-256 и устанавливается
  вспомогательным PowerShell после закрытия процесса; предыдущий EXE сохраняется как `.previous`.
  Workflow `.github/workflows/release.yml` собирает EXE и SHA-256 для каждого `v*`-тега.
- Кнопки и тумблеры очищают фон перед саморисованием, чтобы не оставлять цветовые артефакты.
- Все `.cs` сохранены в UTF-8 без BOM и с LF; сборка по-прежнему использует только
  штатный `csc.exe` и `build.ps1`.
