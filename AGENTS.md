# CacheTrim: памятка для разработчика и ИИ

## Назначение и безопасность

CacheTrim — настольное приложение Windows для очистки и настройки ПК, которым пользуются и друзья владельца. Приложение запрашивает права администратора; ошибочное удаление или системная настройка может навредить. Не обещай прирост FPS. Не отключай службы, антивирус, защиту, не удаляй файлы пользователей и не меняй параметры без понятного подтверждения и возможности корректного отката. Тесты удаления запускай только в созданных для них временных каталогах. Не публикуй неподтверждённую сборку как работающую.

## Что где

- `wpf/CacheTrim.Wpf.csproj` — актуальная основная программа, WPF на .NET 10, Windows x64. `MainWindow.xaml.cs`, `MainWindow.Pages.cs` и другие `MainWindow.*.cs` — частичные классы интерфейса; `App.xaml.cs` — запуск, включая режим `--silent`.
- `winui/Core/` — актуальная логика, подключаемая в WPF-проект: очистка, конфигурация, Windows API, автозагрузка, планировщик, обновление и запуск команд. `winui/TweakCatalog.cs` — каталог системных настроек. Старые исходники в `src/` не являются точкой входа текущей WPF-сборки.
- `companion/DesktopPet/` — Клод: отдельное прозрачное окно поверх рабочего стола, а не виджет внутри CacheTrim. Картинки лежат в `Assets/`. Кнопка во вкладке «Питомец» проверяет и запускает отдельный `DesktopPet.exe` из GitHub Release.
- `winui/Core/CleanupOptions.cs` — исключения, выбор браузеров и минимальный возраст файлов; повреждённые настройки останавливают очистку. `CleanupPresets.cs` сохраняет только флаги категорий. `FileReview.cs` только ищет крупные файлы, дубликаты, установщики и записи, ничего не удаляет.
- `winui/Core/GameGuard.cs` — приблизительная защита от запуска обслуживания во время игры; процесс игры добавляется по EXE, полноэкранный режим определяется Windows. `TaskSetup.cs` содержит отдельное необязательное ежедневное расписание, ограниченное простоем и питанием от сети.
- Выбор компаньона на вкладке «Питомец» предлагает Клода и отдельно предоставленный пользователем AnimeAvatar.exe. По прямой просьбе владельца его неизменённые части встраиваются в приложение как ресурсы и восстанавливаются при первом запуске; код сборки и проверки — `winui/Core/AnimeAvatarPackage.cs`. Исходников и цифровой подписи аватара нет. Закреплённый SHA-256 подтверждает только совпадение с присланным файлом, не безопасность; перед запуском показывается предупреждение о возможных правах администратора. Уведомления компонентов доступны во вкладке питомца. Не внедряй функции Клода в этот EXE. Реальный запуск аватара ещё требует проверки.
- В меню Клода «Принеси секрет» показывает случайную вещь и сохраняет её в коллекцию; текст песни временно приостанавливается, чтобы не перекрыть сообщение. «Почему нет текста песни?» показывает состояние поиска.
- `companion/DesktopPet/LyricsService.cs` и `LyricsTimeline.cs` — необязательные метаданные медиасеанса и поиск синхронных строк через LRCLIB; по умолчанию выключено, включение требует согласия пользователя. Аудио не отправляется и не транскрибируется. При нескольких проигрывающих приложениях приоритет у Spotify для Windows; Spotify в браузере определяется как браузер. После сетевого поиска повторно проверяется текущий трек; пустая строка или пауза скрывает только текст песни, не обычную реплику. Ответы Retry-After учитываются между сменами треков.
- `winui/Core/NetworkDiagnostics.cs` — только по запросу пользователя DNS и четыре ICMP-проверки выбранного адреса, без сброса и изменения сети. `DisplayDiagnostics.cs` читает текущий режим и варианты частот по данным Windows, не меняя настройки.
- `tests/` — тесты и Windows smoke-проверки. `.github/workflows/` — сборка, проверки и публикация. `RELEASE_NOTES.md` — описание текущего выпуска; `wpf/ReleaseHistory.cs` запрашивает описания пропущенных релизов для окна «Что нового».
- `docs/` — изображения документации; `tools/` — вспомогательные инструменты. `dist/`, `bin/`, `obj/` — результаты сборки, не источник истины.

## Проверка и выпуск

1. Проверь текущие `main`, открытые ветки и последнюю версию релиза перед изменениями.
2. Собирай WPF и Desktop Pet под Windows, запускай `tests/WhatsNewTests`, `tests/CleanerSafetyTests`, `tests/FileReviewTests`, `tests/TaskSetupTests`, `tests/CleanupPresetsTests`, `tests/NetworkDiagnosticsTests`, `tests/DisplayDiagnosticsTests`, `tests/LyricsTests`, `tests/PetUiTests`, `tests/UpdateSafetyTests` и Windows smoke-проверки. Проверки GitHub Actions не заменяют визуального тестирования и тестов на реальных устройствах.
3. Версии в `wpf/CacheTrim.Wpf.csproj` и `winui/Core/AppInfo.cs` должны совпадать. В выпуске нужны `CacheTrim.exe`, `DesktopPet.exe` и отдельные файлы SHA-256. Не перезаписывай ранее опубликованные EXE и контрольные суммы: ими пользуется обновлятор друзей.
4. Сохраняй описание изменений и указывай ограничения. Если история GitHub недоступна, приложение показывает заметки текущего релиза с предупреждением. Старые релизы могут не иметь подробных заметок.
5. После работы обновляй эту памятку, не записывай в неё токены, пароли или приватные данные.

## Известные ограничения на момент создания этой памятки

- Жидкое стекло использует Desktop Acrylic на поддерживаемой Windows 11, иначе сплошной фон. Внешний вид на разных устройствах ещё не проверен вручную.
- Клод может запускаться без сети: `PetCache` сверяет файл с SHA-256, встроенным в CacheTrim, и держит файловый дескриптор открытым до запуска. При первой загрузке нужен GitHub Release той же версии. Для верифицированного питомца v2.1.15 предусмотрен запасной вариант с явным согласием; контрольная сумма встроена отдельно. Не запускай непроверенную копию, особенно при правах администратора. Сборка релиза сначала собирает питомца и передаёт его SHA-256 через `TrustedDesktopPetSha256` в WPF; нельзя использовать в готовом релизе значение по умолчанию от старой версии. Индикатор долгой операции — неопределённый прогресс, не процент.
- У отката игрового профиля без сохранённой копии могут использоваться стандартные значения вместо прежних пользовательских. Не называй такой откат точным.
- Питомец не распознаёт речь из системного аудио. Текст песни, если поддерживается в текущей ветке, получается из метаданных совместимого медиаплеера и внешнего сервиса только после согласия пользователя; звук не отправляется. Наличие и синхронизация текстов зависят от плеера и сервиса.
- Защита игр не распознаёт все игры; уже запущенные системные утилиты не прерываются. Проверка файлов при очистке выполняется периодически, а не непрерывно. Расписание запускается только при включённом сеансе пользователя и по текущим сохранённым настройкам; Windows может запустить пропущенную задачу позже.
- Фактический запуск задачи планировщика, текст песен с реальным проигрывателем, аниме-аватар, внешний вид и работа аудио на настоящем ПК нуждаются в ручной проверке.
- Экспериментальные изменения из ветки не являются релизом до прохождения всех проверок и публикации. Уточняй фактический статус по GitHub, не по названию файла.
