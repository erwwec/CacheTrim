В этой версии:

- Окно «Что нового» показывает изменения всех пропущенных версий при обновлении. История загружается с GitHub; если она недоступна, показываются заметки текущей версии.
- Очистка Windows Update больше не удаляет базу очереди фоновых загрузок BITS.
- Очистка временных файлов не затрагивает папки других пользователей и не переходит через ссылки на каталоги; пользовательские дампы удаляются только при выборе категории дампов.
- Выключение реакции питомца на звук теперь останавливает обработку аудио; настройка сохраняется после перезапуска.
