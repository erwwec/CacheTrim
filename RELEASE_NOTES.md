В этой версии:

- Добавлена вкладка «Питомец»: CacheTrim скачивает Desktop Pet по запросу, сверяет SHA-256 и запускает Клода на рабочем столе.
- После установки обновления появляется окно «Что нового» с заметками этого релиза.
- Питомец и CacheTrim поставляются отдельными файлами; питомец загружается только при первом запуске из вкладки.
