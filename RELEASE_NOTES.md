В этой версии:

- При долгих операциях появилась заметная полоска ожидания с названием действия, без выдуманных процентов.
- Клода можно запустить без интернета, если подходящий файл уже скачан и проходит проверку встроенной контрольной суммы. При первой загрузке версии нужен интернет; при наличии проверенной версии 2.1.15 можно отдельно согласиться запустить её.
- В CacheTrim появился поиск по разделам и функциям (Ctrl+F). В настройках можно выбрать сочетания Ctrl+Alt+F7–F12 для открытия CacheTrim и запуска Клода; они работают, пока приложение открыто или свёрнуто, и могут быть заняты другой программой.
- В меню Клода можно настроить непрозрачность, запомнить стартовое положение, включить автозапуск и повторяющиеся напоминания со своим текстом. Напоминания работают только пока Клод запущен и не показываются в режиме «Не отвлекать».
- В меню Клода добавлены команды показать рабочий стол и открыть загрузки; закрыть питомца можно прежней кнопкой «Выход».

Важно:
- При автозапуске Windows запускает Клода напрямую от текущего пользователя, без проверки CacheTrim при каждом входе. Включение спрашивает согласие; отключить можно в меню питомца.
- Для текста песен по-прежнему нужны совместимый плеер, интернет и синхронизированный текст в LRCLIB. Работа со Spotify на разных ПК требует отдельной проверки; аудио не отправляется.
- Аниме-аватар предоставлен как готовый EXE без исходного кода и цифровой подписи. Его безопасность не подтверждена; при запуске он может получить права администратора.
- Выборочная очистка игровых лаунчеров, игровые профили с точным восстановлением, выборочное закрытие программ и настройки GPU пока не реализованы.
