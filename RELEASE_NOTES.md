В этой версии:

- Облачко и меню Клода обновлены; настройки сгруппированы по разделам. Кнопки управления окном CacheTrim стали аккуратнее.
- В разделе «Питомец» появилась кнопка перезапуска выбранного компаньона; CacheTrim пытается закрыть только свой файл и не завершает его принудительно.
- Исправлена настройка рамки окна для эффекта Desktop Acrylic. Видимость размытия по-прежнему зависит от Windows, энергосбережения и активности окна.
- Для аниме-аватара можно выбрать отдельную горячую клавишу в настройках CacheTrim. При запуске сохраняется предупреждение о безопасности.
- В окне сведений об аниме-аватаре появилось понятное объяснение на русском. Технические сведения и уведомления автора на английском сохранены и доступны по раскрывающейся строке.
- При скачивании последующих обновлений CacheTrim будет показывать количество скачанных мегабайт и процент, если известен размер файла. Если размер неизвестен, появится движущаяся шкала без выдуманного процента. После загрузки отдельно показывается проверка файла.
- Сохранён запуск ранее проверенного Клода без сети, в том числе версии 2.1.16 после подтверждения.

Важно:
- Загрузка этого обновления выполняется установленной старой версией CacheTrim: новая шкала появится только при следующем обновлении после установки 2.1.17.
- Аниме-аватар предоставлен как готовый EXE без исходного кода и цифровой подписи. Его безопасность не подтверждена; при запуске он может получить права администратора.
- Для текста песен нужны совместимый плеер, интернет и синхронизированный текст в LRCLIB. Работа со Spotify на разных ПК требует проверки; аудио не отправляется.
- Выборочная очистка игровых лаунчеров, игровые профили с точным восстановлением, выборочное закрытие программ и настройки GPU пока не реализованы.
